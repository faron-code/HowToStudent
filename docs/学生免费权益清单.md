## 🪪 通用：怎么证明"我是学生"

不同平台要求略有差别，常见材料（准备 1–2 种即可）：

1. **学校发放的教育邮箱**（最省事，如 `.edu` / `.edu.cn` 学校邮箱）；
2. **带日期的学生证 / 校园卡**（需显示当前在读、注册日期）；
3. **在读证明 / 学信网学籍验证报告**（中国学生常用，学信网 https://www.chsi.com.cn 可生成）；
4. 录取通知书、成绩单等官方在读材料。

> 注意有效期：多数教育授权**每 1 年或每 2 年需要重新验证一次学生身份**，毕业后自动失效或转为付费。

## 🚨 避坑提醒

1. **认证全程免费**：GitHub、JetBrains、Autodesk 的学生认证都不收钱；凡是"收费帮你过学生认证、卖教育账号、卖学生包邀请"的，都是违规且高风险（封号、隐私泄露、被骗钱）。
2. **不要商用、不要共享**：教育 license 绑定本人身份，商用或多人共用会被取消资格。
3. **认准官网域名**：从上面官方域名进入，不要在淘宝/闲鱼/陌生链接里"代领"。
4. **留意年龄与地区限制**：部分权益要求 18 岁以上，或仅对部分国家/地区开放。
5. **毕业前做好迁移**：教育授权到期后，私有仓库、云资源、云端文件可能受影响，提前备份或转为付费/免费个人版。
