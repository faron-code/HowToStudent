## 📌 这是什么

很多改变命运的机会——奖学金、保送、竞赛、补贴、免费软件、报销——**从来不是按能力分配的，而是按「知不知道」分配的**。

这些信息分散在教育部、考试院、学校官网、政府公告的各个角落，被营销号和付费机构反复加工、夸大、甚至造假。本项目想做一件事：

> **把学生时代「能加的分、能领的钱、能白嫖的资源、要避开的坑」全部整理成一份可检索、可核验、持续更新的公开手册，并且只引用官方文件。**

- 📚 覆盖初中 → 高中 → 本科 → 研究生全学段
- 🇨🇳 按省份标注差异（政策各省不同，绝不以偏概全）
- 🔗 每条结论都附**官方链接**，可自行核对，不搞「我听说」
- 🧑‍🤝‍🧑 完全开源，任何人都可以补充、纠错

## ✅ 内容标准（本项目的底线）

为了和营销号、AI 拼凑内容划清界限，**每一条内容都必须包含以下字段，缺一项不予收录：**

- **适用人群**：学段（初中/高中/本科/研究生）+ 适用省份/学校
- **成本**：要花多少钱、多少时间、有什么门槛
- **收益**：能拿到钱、加分、资格还是资源，价值多大
- **时间节点**：报名/申请的起止时间
- **官方来源**：政府、考试院、学校、主办方官网的**原始链接**
- **证据等级**：`A=官方文件` ＞ `B=学校/主办方通知` ＞ `C=权威媒体报道`（不收 C 级以下内容）
- **核实日期**：政策每年都变，超过一年的内容会被标记「待复核」

## 🤝 如何贡献

一个人覆盖不了全国所有省份和学校，**这本手册需要每一个人一起补全。**

你可以做这些（哪怕只改一个错别字、补一个链接都非常欢迎）：

1. **补充你所在省份/学校的政策**（尤其是强基、专项、补贴、落户等地方差异大的内容）
2. **纠错**：发现过期、失效链接或不准确的描述，提 Issue 或直接 PR
3. **补充时间轴**：你所在学段今年的报名/申请节点
4. **分享给可能需要的人** ⭐

请先阅读 [`CONTRIBUTING.md`](./CONTRIBUTING.md) 和内容模板，按标准格式提交。提交 PR 即表示你同意以 [CC BY-NC-SA 4.0](./LICENSE) 协议共享你的内容。
